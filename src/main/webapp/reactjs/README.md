# Projet Full Stack - Gestion de Voitures avec IA

## Description

Ce projet est une application Full Stack de gestion de voitures.

Il contient :

- Un backend Spring Boot
- Un frontend React
- Une base de données MariaDB avec Docker
- Une intégration IA métier avec Spring AI et Ollama
- Une documentation Swagger

L'application permet de gérer des voitures : ajout, affichage, modification et suppression.

Une page **Assistant IA** a été ajoutée. Elle permet de conseiller une voiture à l'utilisateur selon les voitures disponibles dans la base de données.
